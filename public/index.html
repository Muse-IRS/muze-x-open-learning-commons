Chaque ressource conserve sa provenance. Une relation dessinée dans le maillage reste une relation qualifiée : elle ne devient pas une preuve par visualisation.

Autonomie

La plateforme propose.
L’utilisateur décide.

Pas d’autoplay forcé, pas d’urgence artificielle, pas de contribution sollicitée comme objectif produit. Apprendre peut mener à explorer un module. Explorer peut donner envie d’apprendre un nouveau concept. Contribuer reste une possibilité.

Pont multi-domaine

Open Learning Commons ↔ Muze-X Lab

Le commun organise la compréhension et les ressources. Muze-X Lab accueille les explorations publiques par domaine. Le passage entre les deux peut transporter un contexte conceptuel public, jamais un profil personnel requis.

Bootstrap sans profil. Cette version ne crée aucun compte, n’utilise aucun jeton YouTube, ne stocke pas la recherche et n’infère aucun intérêt depuis les mouvements du champ visuel. Les données affichées proviennent du graphe JSON public versionné dans le dépôt.
