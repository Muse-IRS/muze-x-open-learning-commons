## Current objective

Operate a minimal public learning aggregator before external API adapters are introduced.

The current deployment now separates two surfaces:

```text
OPEN LEARNING
→ public learning-resource aggregation
→ concepts + provenance + domain mesh

SWARM FIELD LAB
→ dedicated reactive visual-field controls
```

Open Learning keeps the swarm as ambient interface language and the bottom Muze-X anchor, but no longer exposes swarm mode/speed controls inside the learning task.

The starter learning field combines existing Muze-X modules with a small manually verified catalog of external public educational resources. Inclusion is a discoverability relation, not a content endorsement.

## Promotion rule

A concept, relation, resource or feature is not promoted merely because it is visually compelling or intuitively plausible. Promotion requires explicit provenance, bounded wording, counterexample consideration and a public reason for inclusion.

```text
SOURCE_SUPPORTED != PROVEN
INDEXED_RESOURCE != ENDORSED_CLAIM
VISUAL_METAPHOR != COGNITIVE_MODEL
RELATION != CAUSATION
```
