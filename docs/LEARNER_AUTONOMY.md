# Learner Autonomy

Canonical invariant:

```text
PLATFORM_PROPOSES
USER_DECIDES
```

The learner may search, open, ignore, compare, leave, return or contribute.

The system must not use dark patterns, forced autoplay, concealed persuasion, artificial urgency or contribution pressure as learning mechanisms.

Personalization, if introduced later, must remain separable from legitimacy and user control:

```text
USEFUL != AUTOMATICALLY_DESIRED
PERSONALIZED != AUTOMATICALLY_LEGITIMATE
```

A future adaptive layer should expose what signal is used, for what purpose, and how the learner can disable or reset it.
