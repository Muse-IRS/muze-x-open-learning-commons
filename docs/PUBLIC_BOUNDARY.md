# Public Boundary

This repository is public and open source.

Allowed:

- public-facing code;
- synthetic fixtures;
- public metadata;
- source URLs;
- concept and relation graphs;
- transparent exploratory algorithms;
- user-facing documentation.

Excluded:

- personal data or case files;
- secrets and credentials;
- private prompts;
- confidential research artefacts;
- hidden behavioural profiles;
- copyrighted media copied without a clear right to publish;
- claims presented with more certainty than their sources support.

Publication invariant:

```text
PUBLIC_RESULT
<=
PUBLICLY_JUSTIFIABLE_EVIDENCE
```
