# Project Charter

## Purpose

Build a public learning commons that connects educational resources and Muze-X domain modules through a traceable concept graph.

## Core proposition

```text
PUBLIC_RESOURCES
+
PROVENANCE
+
CONCEPT_RELATIONS
+
LEARNER_CHOICE
=
NAVIGABLE_KNOWLEDGE_MESH
```

## Non-goals

The project is not intended to:

- prove a theory of cognition;
- infer hidden beliefs from visual interaction;
- maximize attention capture;
- replace original creators;
- re-host entire external catalogues;
- present exploratory relations as scientific laws.

## Durable loop

```text
LEARN -> EXPLORE -> OPTIONAL_CONTRIBUTION
  ^                         |
  |_________________________|
```

A new domain module may enrich the learning commons; the learning commons may reveal a domain worth exploring.
