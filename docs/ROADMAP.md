# Roadmap

## Phase 0 — Public bootstrap

- public governance and license;
- schemas for resources, concepts and relations;
- starter knowledge mesh;
- responsive GitHub Pages interface;
- reactive dual-swarm visual field;
- bidirectional Muze-X Lab bridge.

## Phase 1 — Resource commons

- contributor-friendly source registry;
- source deduplication and provenance checks;
- concept search and graph exploration;
- public contribution workflow.

## Phase 2 — Public adapters

Evaluate source adapters one by one. Keep credentialed adapters optional and separated from the core.

Candidate sources: YouTube public metadata, open course catalogues, podcasts, public archives and open educational resources.

## Phase 3 — Learning paths

- user-selected learning objectives;
- explicit local progress state;
- compare sources;
- spaced revisit as an opt-in feature;
- no hidden engagement optimization.

## Phase 4 — Domain creation bridge

Allow a learner to discover the public process for proposing a new Muze-X Lab exploratory module.
