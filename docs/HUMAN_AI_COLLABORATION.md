# Human / AI Collaboration

GitHub is the durable public authority for the project state. Humans and AI systems may propose changes through the same versioned surface.

```text
HUMAN ─┐
       ├─> GITHUB MAIN / ISSUES / PULL REQUESTS -> PUBLIC STATE
AI ────┘
```

A contributor identity does not establish factual authority. Claims remain bounded by their sources and qualification.

The repository should remain understandable if the current model, interface or contributors change.

```text
MODEL_REPLACEMENT != PROJECT_MEMORY_RESET
```
